# Marketing screenshots

Demo Mode screenshots of DashyNMS Mobile captured from `main` at commit `b512b27` (`v2.0.0-edge.7`). Every screen uses the built-in example network (`*.example.net` and RFC 5737 test addresses). Sign-in screens show only the empty `nms.example.com` placeholder.

The iPhone 18 Pro and iPad Schedule maintenance screenshots were retaken for #698.

## Selection notes

- Pick the Temperature shots (`42-health-temperature-dark.png`, `42-duo-unfolded-health-temperature-dark.png`, `41-ipad-landscape-health-temperature-dark.png`) when showing Health. They include Critical, Warning, and OK sensors on one screen, whereas the earlier dBm shots (`18` and `15`) show only green OK rows.
- Pick `46-duo-unfolded-intelligence-graph-clean-dark.png` over `25-duo-unfolded-intelligence-graph-dark.png`. Shot `46` aligns the side glass rail to dark mode and keeps the prompt and full-size traffic chart in frame.
- Pick `44-ipad-landscape-intelligence-overview-top-dark.png` over `25-ipad-landscape-intelligence-overview-dark.png`. Shot `44` shows the prompt, opening summary, and top of the alerts table instead of only the scrolled tail.
- For an Intelligence shot with a full-size inline traffic chart, use `iphone-duo/46-duo-unfolded-intelligence-graph-clean-dark.png`. On iPhone 18 Pro (`30`) and iPad (`26`), Intelligence displays attached graphs as small thumbnails. For a compact Intelligence answer that fits cleanly on every device, use the unreachable-devices shots (`45`).
- On iPhone Duo, files `33` to `36` carry `landscape` in their names because `orientation landscape-left` produced them, which rotates the unfolded display to `2007x2853` tall portrait.
