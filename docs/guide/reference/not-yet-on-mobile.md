# What Mobile doesn't do yet

Some jobs need [DashyNMS on a computer](https://github.com/DashyNMS/desktop/wiki) or the LibreNMS website.

| Job | On Mobile |
| --- | --- |
| Edit alert rules and templates | Read only |
| Add, edit or delete a device | Not available |
| Custom maps | Not available |
| Take a Unimus backup now | Not available. You can read and compare backups. |
| Intelligence on Android | Not available in 2.0 |
| Intelligence with ChatGPT or another provider | Not available. Apple Intelligence answers on the device. |
| Web search in Intelligence | Not available |
| A demo without a server | Not available yet |
| Instant alerts | Notifications come from [checks](../how-to/notifications.md), so they can be late. |

Dashboards, pins and settings aren't copied between a computer and a phone.
