# Read logs

## Event log and alert log

1. Open **More → Event and alert logs**, or **See all** on an **Event log** card.
2. Switch between **Event log** and **Alert log**.
3. Narrow by device, type or state, time range and **Auto-refresh** using the filter chips or the **Filters** control on narrower panes. Choose **Clear filters** to return to all entries.
4. Search what's loaded, and choose **Load more** or **Look further back** for older entries.

Entries sit under a heading for each day. Tap one to read it in full and open its device. A device's own event log is on the device's page.

Search covers only the entries already loaded, so load more before deciding something isn't there.

## Graylog messages

1. [Connect Graylog](integrations.md#connect-graylog) if you haven't.
2. Open **More → Graylog**, or **Graylog** on a device's page.
3. Narrow by time range, level and stream. Type a search and choose **Search** on the keyboard to send it to Graylog.

Tap a message for every field and the way to its device. Messages are matched to devices by address or name.

## Keep a log up to date

Turn on **Auto-refresh** and choose how often. It runs only while the log is on screen. New entries appear at the top without moving what you're reading, and a failed refresh keeps what's already there.
