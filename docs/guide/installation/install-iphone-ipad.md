# Install on iPhone and iPad

DashyNMS Mobile needs iOS or iPadOS 15 or later. Some features need a newer system:

| Feature | Needs |
| --- | --- |
| Alerts, devices and notifications | iOS 15 |
| Home screen widgets | iOS 16 |
| Lock screen widgets | iOS 16 and an iPhone |
| Intelligence | iOS 26 or later, a device that supports Apple Intelligence, and Apple Intelligence turned on |

## Install

The app isn't in the App Store yet. It's in TestFlight, Apple's app for trying apps before release, and you need an invitation.

1. Check the [DashyNMS Mobile page](https://dashynms.pckp.net/mobile/) for how to get the app now. If it doesn't say how to join, ask through the [support page](https://dashynms.pckp.net/mobile/support/).
2. Install the app from your invitation and open it.
3. Follow [Getting started](../getting-started.md) to sign in.

When DashyNMS asks to send notifications, choose **Allow** if you want to hear about alerts. You can change this later in the phone's own Settings app.

## Update

The App Store updates DashyNMS with your other apps. A TestFlight build updates through TestFlight. After an update, **What's new** shows once; open it again from **Settings → What's new in this version**.

## Remove

In **Settings**, choose **Sign out**, then **Sign out and forget everything**, before deleting the app. Deleting an app on its own can leave the saved token in the phone's keychain. To cancel the token itself, revoke it in LibreNMS.
